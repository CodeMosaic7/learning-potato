# V1 Product Specification & Target Architecture Documentation

## Overview

This directory contains the official **V1 Product Specification and Target Technical Architecture** for rebuilding the **Mello.ai (Learning-Potato)** platform.

> [!IMPORTANT]
> **Source of Truth Notice**: This documentation set defines the approved target specifications and architecture for the upcoming rebuild. Historical codebase defects and audit findings are preserved separately in `docs/current-system-audit/`. No application source code was modified during this specification phase.
